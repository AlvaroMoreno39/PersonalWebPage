GhostNode - HTB

Red Team Medium Linux Web Exploitation Enumeration Privilege Escalation Log Analysis

Overview

GhostNode is a medium Linux machine where the initial foothold is achieved through web misconfiguration and endpoint enumeration. The post-exploitation phase focuses on reviewing local logs, extracting useful operational data, and abusing a weakly controlled maintenance task to escalate privileges.

Recon

nmap -sC -sV -p- 10.10.10.200

Initial findings exposed SSH and an HTTP service with a restricted admin path.

Web Path

Directory and endpoint enumeration identified hidden API routes and a weak token validation flow.

ffuf -w /usr/share/seclists/Discovery/Web-Content/common.txt -u http://10.10.10.200/FUZZ

Post-Exploitation

Local log files revealed task execution context and reusable credentials for a privileged process.

grep -R \"token\\|cron\\|backup\" /var/log 2>/dev/null

Privilege Escalation

A maintenance script executed with elevated permissions accepted user-controlled input, enabling escalation.

Takeaways

  • Endpoint enumeration still provides high-value pivots in medium boxes.
  • Operational logs can expose real escalation vectors.
  • Weak validation in maintenance tooling is frequently exploitable.
